# Grok 4.6 circuit reconstruction tasks

This folder contains five circuit-reconstruction task families. Each family has `mid`, `hard`, and `harder` Harbor packages, and every runnable package contains its own `task.toml`.

## Task families

- `sample-1-zero-if-rf-soc`
- `sample-2-wimax-transceiver`
- `sample-3-bluetooth-transceiver`
- `sample-4-medradio-receiver`
- `sample-5-rf-sampling-receiver`

## Prompt for finding a task

Find the Grok 4.6 circuit-reconstruction tasks under `4.6 tasks/`. Choose the requested sample family and difficulty (`mid`, `hard`, or `harder`), then use the directory containing `task.toml` as the Harbor task root.
